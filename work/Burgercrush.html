Burger crush

Burger crush is een 3-match game gemaakt voor in de McDonalds app.

Opdracht

In opdracht van LiveWall Group heb ik de basis voor een 3-match game zoals Candy Crush gecreëerd voor McDonalds, genaamd Burger Crush. LiveWall maakt verschillende games voor McDonalds die ze in hun apps kunnen zetten waardoor spelers kortingbonnen kunnen verdienen om uit te geven in hun restaurants.

Development

Deze game was gemaakt met Phaser 3, een JavaScript library. De eerste fase bestond uit het opzetten van de basis code om drie items op een rij te detecteren. Daarna werd het uitgebreid naar het creëren van speciale items zoals dat vier op een rij een item creëert waarbij de hele rij verdwijnt. Als laatste werd door het design team een ontwerp aangeleverd in de stijl van McDonalds. Deze was geïmplementeerd met wat animaties tussen de schermen door.
