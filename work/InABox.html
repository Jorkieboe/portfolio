In A Box

Game

In a box is een work in progress puzzle-platform game ontwikkeld door mijzelf. Je speelt als een knuffel egel van het zoontje van een schoenmaker. De schoenmaker heeft een mysterieuze achterkamer, waar andere knuffels verdwijnen. Op een dag besluit de egel de kamer te betreden. Daarbinnen komt hij vast te zitten in een wereld bestaand uit kartonnen dozen. Deze dozen kan je draaien waardoor zwaartekracht verandert. Jouw doel is om deze wereld te ontdekken en alle vermiste knuffels te bevrijden.

Art Style

De game speelt zich af in de achterkamer van de schoenmaker op een bureau waar hij speeldozen maakt voor zijn zoontje. Daardoor hebben de dozen een knutsel achtige look, met papier achtige texturen. In deze donkere kamer schijnt een licht op de doos wat een soort toneel licht voorstelt. Hierdoor ligt de focus op de doos waar ook de game zich afspeelt.

Development

Deze game is gemaakt in Unreal Engine 5 met visual programming met blueprints. De uitdaging van de game was dat UE5 geen andere richting van zwaartekracht ondersteunt. Dit was deels op te lossen door een plugin uit de Unreal marketplace, maar bepaalde game mechanics als movement, pathfinding moesten alsnog aangepast worden om de andere richting te ondersteunen.
